Creating a LEM in Acumatica

DS Home Computing Ltd · SA03 SECOR · For internal use
🔍

QA-PRO-5.1.3Creating a LEM in Acumatica

Purpose

The purpose of this procedure is to outline the correct steps for creating a Labour, Equipment, and Materials (LEM) entry in Acumatica. Accurate and timely LEM completion ensures proper client billing, payroll accuracy, and project tracking.

Scope

This procedure applies to all Leads and Technicians responsible for entering daily or weekly LEMs in Acumatica for DS Home Computing Canadian operations.

Roles & Responsibilities

Field Lead

Complete daily or weekly LEMs for all personnel and equipment assigned to the project.

Ensure accuracy of labour codes, hours, per diems, and expenses.

Submit LEMs before weekly cutoff (Sunday at midnight).

Technicians

Provide the Field Lead with accurate hours and required information.

Project Coordinator / Administration

Review LEM entries as needed.

Ensure LEMs are submitted or signed on time.

Definitions

LEM: Labour, Equipment, and Materials entry used for billing and cost tracking.

Daily LEM: LEM covering one workday.

Weekly LEM: LEM covering an entire week (ending Saturday).

LOA (Living Out Allowance): Per diem or daily allowance.

Procedures

Access the LEM Module

Log into Acumatica.

Navigate to Time & Expenses → LEM.

Select the Correct Date

For weekly LEMs, select the Saturday cutoff date.

For daily LEMs, select the current day.

Complete Header Information

Enter the Field Lead’s name (search using the magnifying glass or type it manually).

Enter the Project ID.

Select the appropriate Task (usually “In Scope Work,” but confirm if different).

Enter a brief description of the work performed that day.

Keep descriptions clear and concise.

Important: The top section must be fully filled out before adding labour or expenses. Failure to do so will cause all added information to erase.

Add Labour

Scroll to the bottom section.

Click Apply Template (+) under Labour.

Select the worker’s name.

Select the correct labour code based on trade and role.

Example: Instrument Tech Overtime = OT2

Enter the number of regular hours worked.

For overtime:

Add a new labour line

Select appropriate OT labour code

Enter overtime hours

Per Diem / LOA

Add another Labour line.

Enter LOA in the labour code search bar.

Enter number of days (not hours).

Daily LOA → 1 day

Weekly LOA → typically 7 days

Add Expenses

Go to the Expenses section.

For truck usage:

Select the daily truck rate

Enter number of days

Mark Non-Billable Time (If Applicable)

If the time cannot be billed to the client (e.g., safety training), ensure the Non-Billable checkbox is selected, otherwise the time will be billed.

Save the LEM

Click Save once all labour, LOA, and expenses are complete.

Reviewing and Editing LEMs

Go to Data Views → LEM List.

Select the LEM you wish to review.

Edits can only be made when the LEM status is On Hold.

Once the status changes, edits cannot be made

Submission Requirements

All LEMs must be completed by Sunday at midnight.

LEMs are sent to the client Monday morning unless signed on-site.

Frequency and Review Period

This procedure will be reviewed annually or sooner if Acumatica updates affect LEM entry functionality.
